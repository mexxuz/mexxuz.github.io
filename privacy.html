Privacy Policy

Last updated: October 6, 2026

This policy describes how Boom and Bust Uploader (the "App"), a private tool operated by the owner of the Boom & Bust YouTube channel, handles data.

Who uses the App

The App is used only by the channel owner to manage the owner's own YouTube channel. It is not available to the public.

What data the App accesses

When the channel owner signs in with Google, the App receives an OAuth access token for the YouTube Data API with these permissions: uploading videos (youtube.upload) and managing the channel's own videos, captions and playlists (youtube.force-ssl). The App uses them only to upload the channel's own videos and to set their metadata, thumbnails, captions and publish schedule.

What the App stores

The OAuth token is stored only on the channel owner's own computer. Video files and metadata are the owner's own content. The App does not collect, store or process data about viewers or any other YouTube users, and does not use analytics or advertising trackers.

Sharing

The App does not sell, share or transfer any data to third parties. Data is sent only to Google/YouTube through the YouTube API Services.

YouTube API Services

The App uses YouTube API Services. By using the App you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page: myaccount.google.com/permissions. The locally stored token can be deleted at any time.

Data retention and deletion

The App keeps no copies of YouTube data. The OAuth token is kept only until access is revoked; deleting it from the owner's computer, or revoking access in Google security settings, removes all stored authorization data immediately. Any YouTube API data the App reads (the channel's own video list) is used only during a single upload session and is not stored.
